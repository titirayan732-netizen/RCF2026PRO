# 🕌 ريلز القرآن الكريم Pro

**استوديو ويب لصناعة مقاطع فيديو قرآنية (ريلز) احترافية** — نص عثماني بروايتي حفص وورش، تلاوات متعددة، ترجمات، تفسير، تأثيرات بصرية، وتصدير مباشر لمقاسات إنستغرام وتيك توك ويوتيوب.

![غلاف المشروع](og-cover.png)

> ملاحظة: هذا المشروع **واجهة تجميع فقط** — النصوص والتلاوات والخطوط حقوقها لأصحابها (انظر [المصادر والتراخيص](SOURCES.md)).

## ✨ المزايا

- 📖 **روايتان**: حفص عن عاصم وورش عن نافع — نصًا وصوتًا وخطًا، بلا خلط بينهما.
- ✒️ **خطوط مصحفية رسمية**: KFGQPC (حفص/ورش) + خط ورش العثماني الأصلي + بدائل متوافقة.
- 🎙️ **تلاوات متعددة** لكل رواية + رفع ملف صوتي يدوي، بمزامنة تلقائية بين النص والصوت.
- 🌍 **8 ترجمات** (إنجليزية، فرنسية، إسبانية، ألمانية، إندونيسية، أردية، تركية، روسية) + **المختصر في التفسير**.
- 🎬 **تأثيرات**: دخول (تلاشي، انزلاق، صعود، ضباب، تقليب، تكبير، ظهور)، أنماط نصية (توهج، حدود، تدرج، نيون...)، وحركات مستمرة (موجة، تنفس، طفو...) — للآيات والترجمة والشعار والتذييل.
- 🕌 **شعار دائري** باسم ملازم + 📜 **تذييل مخصص** — يُرسمان داخل الفيديو المصدَّر.
- 🎨 **4 سمات لون** للصفحة (ذهبي، أخضر ملكي، بنفسجي ملكي، برتقالي).
- 📐 **3 مقاسات**: عمودي 9:16، مربع 1:1، أفقي 16:9 — والمعاينة تتبع المقاس تلقائيًا.
- 💾 **مشاريع محلية**: حفظ تلقائي + حفظ/تحميل/تصدير ملفات + تراجع/إعادة — بلا حساب ولا خادم.
- 📱 **تطبيق PWA**: يعمل دون اتصال (صفحة خاصة)، وقابل للتثبيت على الهاتف.

## 🚀 التشغيل محليًا

لا يحتاج بناءً ولا خادمًا — افتح `index.html` مباشرة في المتصفح، أو من سطر الأوامر:

```bash
# أي خادم ملفات ثابتة، مثلاً:
npx serve .
```

> الجلب (السور، النصوص، الصوت، الترجمة) يحتاج إنترنت. المشاريع تُحفظ في `localStorage` على جهازك.

## 🌐 النشر على Netlify

1. اسحب مجلد المشروع إلى [app.netlify.com/drop](https://app.netlify.com/drop).
2. الإعدادات: **Build command فارغ** — **Publish directory: `.`**
3. فعّل: تحسين الأصول (Minify) + Pretty URLs + فرض HTTPS.
4. ⚠️ **بعد النشر**: استبدل النطاق المؤقت `quran-reels-pro.netlify.app` برابط موقعك في: `index.html` (canonical و Open Graph و JSON-LD) و `robots.txt` و `sitemap.xml`.

ملف `netlify.toml` مضبوط مسبقًا (تخزين طويل للأصول المبصمة، حماية Service Worker من التخزين، ترويسات أمنية).

## 🗂️ بنية المشروع

| المسار | الوصف |
|---|---|
| `index.html` | الواجهة كاملة (RTL، عربية) |
| `css/` | الأنماط (`base.css` + `responsive.css` للتجاوب) |
| `js/` | المنطق مقسمًا: `state` (الحالة)، `api` (الجلب)، `quran` (الآيات)، `audio`/`video` (الصوت والتوقيت)، `canvas` (الرسم والتأثيرات)، `timeline`، `projects` (الحفظ)، `presets` (القوالب)، `ui`، `app` (الإقلاع) |
| `sw.js` / `offline.html` / `404.html` | العمل دون اتصال وصفحة الخطأ |
| `manifest.webmanifest` + الأيقونات | التثبيت كتطبيق (PWA) |
| `SOURCES.md` | كل مصدر خارجي وغرضه |
| `netlify.toml` / `robots.txt` / `sitemap.xml` | النشر والأرشفة |

## ⌨️ أساسيات الاستخدام

1. اختر السورة والرواية والنطاق، ثم **جلب الآيات**.
2. جهّز صوت المقرئ (أو ارفع ملفًا صوتيًا).
3. خصص الخطوط من تبويب الآيات، والتأثيرات من تبويب التأثيرات.
4. أضف شعارك ونص التذييل إن أردت.
5. **تصدير** بالجودة والمقاس المطلوبين.
